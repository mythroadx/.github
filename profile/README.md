## 项目简介

**MrpX** 是一个基于 [VMRP](https://github.com/vmrp/vmrp) 项目的架构重构与工程化改进项目。

本项目以原始 VMRP 模拟器为基础，借助 AI 辅助开发，对项目架构进行重新梳理与重构，致力于提升代码组织、工程结构、可维护性以及现代化开发体验。

MrpX 并非一个从零开发的 MRP 模拟器，也不主张原始模拟器核心代码的原创权。

**项目的核心工作是架构层面的重构与工程化改进，而不是重新实现原始模拟器。**

## 我的工作

本项目的主要工作集中在以下方面：

- **AI 辅助架构重构：** 借助 AI 工具重新梳理和组织现有代码。
- **工程化改进：** 优化项目结构、模块边界及代码组织方式。
- **现代化改造：** 改善开发体验，使项目更符合现代软件工程实践。
- **可维护性提升：** 为后续功能维护、扩展和持续迭代提供更清晰的工程基础。

上述工作仅代表我在架构重构和工程化改进方面所做的贡献。
